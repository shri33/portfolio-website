# Image Magic — Virtual Staging & Shopify Image Optimizer

**Role:** Lead developer (frontend + image pipeline prototyping)  
**Stack:** Next.js, React, Python image pipelines, OpenCV/ImageMagick, Vercel

## Problem
E-commerce listings often suffer from inconsistent product images — poor backgrounds, mismatched lighting, and low perceived quality. Manually staging images for thousands of SKUs is expensive and slow.

## Solution
I built **Image Magic**, a demo product that automates large parts of the staging and optimization pipeline:
- Background removal and resizing pipelines using Python + ImageMagick/OpenCV.
- Staging templates and composition engine to place products into curated scene photography (virtual staging).
- Web UI (Next.js) for previewing batched results and downloading optimized assets.
- Batch processing & queue system to scale over catalogs.

## Architecture & key decisions
- **Preprocessing**: background removal + alpha extraction using optimized Python scripts; outputs stored in cloud storage.
- **Staging**: template-based composition to maintain consistent lighting and shadows.
- **Frontend**: Next.js app with optimized `next/image`, progressive loading, and preview variants.
- **Scale**: queue-based batch processing to handle catalog-size workloads, with simple horizontal scaling (Docker).
